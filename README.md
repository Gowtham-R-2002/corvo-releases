# Corvo releases

Prebuilt Corvo binaries (Linux x86_64). This repository holds release files only; Corvo's source is not published here.

Install or update: download `corvo-linux-x86_64` from the latest release, or run `corvo update` from an installed Corvo.
Every release ships `latest.json` with SHA-256 checksums and an Ed25519 signature that Corvo verifies before installing.
